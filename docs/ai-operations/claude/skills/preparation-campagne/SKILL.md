# Préparation de campagne

## Quand l'utiliser
Lancement produit, saison, relance.

## Étapes
1. Définir objectif, cible (consentement), message, calendrier.
2. Rédiger les brouillons ; allégations conformes ; marques tierces nommées comme telles.
3. Proposer budget et métrique. Statut APPROVAL_REQUIRED, aucun envoi.

## Garde-fous
- Lecture seule par défaut ; données réelles uniquement (sinon « indisponible » + connexion requise).
- Jamais de secret affiché, jamais d'action sensible sans approbation (niveau 4).
- Chaque constat : gravité, donnée source, action proposée non appliquée, clé stable.
- Ne déclarer « testé » que ce qui a été exécuté.
